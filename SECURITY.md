# Security and privacy

This prototype handles identity documents and face images. Use synthetic
data for demonstrations. Run locally on loopback; the app has no production
authentication, rate limiting, consent workflow or retention policy.

Environment files, local model files, private inputs, caches and outputs
are excluded from Git. Do not attach documents, images, OCR text or secrets
to public issues. Raw OCR diagnostics can contain personal information.

The prototype is not a certified identity-verification or liveness product.
A production deployment requires independent security, privacy, model-license
and biometric performance review.
